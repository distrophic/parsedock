# Безопасность

ParseDock рассчитан на одного пользователя и локальные профили. Профиль считается доверенным: пути в нём не запираются в отдельный каталог.

## Что ограничивает программа

- Только GET. Произвольный код из профиля не выполняется.
- TLS проверяется. Отключение проверки в настройках по умолчанию нет.
- Перед соединением адрес проверяется. Служебные, ссылочно-локальные, multicast и неопределённые адреса закрыты. Частные сети и loopback открываются флагом `trust_private_networks`.
- `requests` и `curl_cffi` открывают сокет только на эти уже проверенные адреса. Имя при connect повторно не спрашивается. Сертификат HTTPS сверяется с именем из адреса.
- Редиректы обрабатываются по одному, у каждого перехода адрес проверяется снова.
- `Authorization`, `Proxy-Authorization` и `Cookie` не передаются, если источник редиректа другой.
- В браузерном клиенте каждый адрес `http` и `https`, включая вложенные запросы, проходит ту же проверку. Чужой источник тоже теряет секретные заголовки.
- Запись JSONL, CSV, SQLite, файла продолжения, профиля из окна и сгенерированного скрипта отклоняется, если сам путь — символическая ссылка.
- Генератор кода не копирует заголовки запроса в скрипт.
- Команды терминала не собираются из адреса страницы.

## Что это не закрывает

- Клиент `playwright` проверяет адрес до запроса, но Chromium разрешает имя сам. Подмена между проверкой и соединением для браузера возможна.
- Запись через символическую ссылку на этой Windows тестом не подтверждалась: ссылку создать не удалось. Код отказа на месте, сценарий здесь пропущен.
- Явное сохранение профиля записывает заголовки, которые вы ввели, включая секреты. Не кладите такой профиль в общий каталог.
- Терминал выполняет введённую команду с правами пользователя.
- Запуск сохранённого скрипта выполняет этот файл.
- Playwright не обходит капчу и не читает ваш обычный профиль Chrome, но скачанная страница — это содержимое сайта.
- 25 сентября 2026 для установленных версий запрошена база OSV: beautifulsoup4 4.15.0, requests 2.34.2, urllib3 2.8.0, charset-normalizer 3.5.1, idna 3.20, certifi 2026.7.22, soupsieve 2.9.2, curl_cffi 0.16.3, PySide6 6.11.2, pytest 9.1.1, playwright 1.63.0. По этим версиям записей не было. Это не проверка встроенных библиотек Qt и libcurl и не постоянный мониторинг.

## Как сообщить

Не прикладывайте секреты, cookie и приватные профили. Опишите версию Python, систему и шаг, после которого появилась ошибка. Пока нет опубликованного репозитория, сообщение остаётся локальным. После публикации — Issues этого репозитория.
