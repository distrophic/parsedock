# История изменений

## 0.1.0

Код опубликован: https://github.com/distrophic/parsedock. Тега релиза и пакета на PyPI нет. Лицензия — MIT.

В этом дереве уже есть:

- профиль схемы 1, разбор HTML и XML, предпросмотр;
- экспорт JSONL, CSV и SQLite;
- один GET, ручные редиректы, проверка адреса, повторы, отмена задания;
- обход страниц и необязательное продолжение;
- дополнительные клиенты `curl_cffi` и Playwright;
- окно PySide6, командная строка, генератор скрипта, сеанс оболочки;
- обычные тесты без внешних сайтов и файл сценария CI для Ubuntu и Windows.

Сценарий CI запускался на Ubuntu 24.04 и Windows для Python 3.10 и 3.12. Зелёный прогон: https://github.com/distrophic/parsedock/actions/runs/38242370481. После строки `passed` выгрузка Qt на Windows может оборвать процесс; шаг смотрит на итоговую строку pytest и не считает это падением тестов.
